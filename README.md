# Full Stack Employee Management System

A full-stack Employee Management System that helps **organizations manage employees, attendance, leave requests, payroll,** and **profiles** through a centralized platform. Built with **React, Node.js, Express,** and **MongoDB** with secure authentication and role-based access.

## Executive Summary

- ✅ **Project scope:** Built a full-stack Employee Management System to streamline employee operations including **employee records, attendance, leave management, and payroll.**

- **System design:** Developed a role-based architecture with separate functionalities for **administrators** and **employees** using secure authentication.
- **Development:** Implemented **frontend, backend,** and database integration using **React, Node.js, Express.js, and MongoDB.**
- **Features:** Delivered employee **dashboards, attendance tracking, leave workflows, payslip generation, and profile management.**
- **Outcomes:** Created a centralized platform that improves **HR workflow efficiency**, **reduces manual processes**, and **provides better employee data management.

## Problem and Context

- ❌ **Problem:** Many organizations still rely on manual processes or disconnected systems for managing employee information, attendance, leave requests, and payroll, leading to inefficiency and data management challenges.

- ❌ **Challenges:** HR teams face difficulties in maintaining accurate employee records, tracking attendance, processing leave approvals, and generating payroll reports efficiently.

- 💡 **Context:** A centralized digital system is needed to automate employee management tasks, improve data accuracy, and provide easy access to important employee information.

- 🎯 **Solution:** Developed a full-stack Employee Management System that enables administrators and employees to efficiently manage HR operations through a secure and user-friendly platform.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS, JavaScript, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose ODM
- **Authentication:** JWT-based authentication, Role-Based Access Control (RBAC)
- **API Communication:** RESTful APIs, Axios
- **Automation:** Inngest for background workflows
- **Development Tools:** Git, GitHub, VS Code, Postman
- **Deployment:** Vercel (Frontend & Backend)

## Installation & Setup

### 1.Clone Repository

`https://github.com/Lasantha201/FullStack-EMS.git`

### 2.Backend Setup

- Navigate to server:
`cd server`

- Install dependencies:
`npm install`

- Start backend:
`npm run server`

### 3.Frontend Setup

- Navigate to client:
`cd client`

- Install dependencies:
`npm install`

- Start frontend:
`npm run dev`
